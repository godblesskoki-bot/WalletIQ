## 🎨 Visual Design Elements

### Color Palette
```
Primary:     #f7931a (Bitcoin Orange)
Background:  Gradient from slate-900 to black
Cards:       slate-800/50 with backdrop-blur
Borders:     slate-700
Text:        white, slate-300, slate-400
Warning:     yellow-400, red-400
Success:     green-400
```

### Typography Sizes
```
Hero Title:        5xl - 6xl (WalletIQ)
Section Titles:    3xl - 4xl (Premium section hero)
Feature Titles:    2xl (Supported Cryptocurrencies)
Card Titles:       xl (Feature cards)
Body Text:         base - lg
Supporting Text:   sm - base
```

### Spacing & Layout
```
Container:       max-w-6xl (premium section)
Card Padding:    p-6
Section Gaps:    space-y-6 to space-y-12
Grid Gaps:       gap-3 to gap-6
Border Radius:   rounded-xl to rounded-2xl
```

## ✨ Interactive Elements

### Crypto Cards
- **Idle**: Subtle background, normal scale
- **Hover**: 
  - Scale: 105%
  - Border glow: Orange
  - Icon scale: 110%
  - Duration: 200ms

### Feature Cards
- **Idle**: Glass background
- **Hover**:
  - Scale: 102%
  - Shadow: xl
  - Icon scale: 110%
  - Duration: 300ms

### Main Info Card
- **Idle**: Standard glass effect
- **Hover**:
  - Scale: 101%
  - Shadow: 2xl
  - Duration: 300ms

### Warning Card
- **Always**: Yellow/red gradient border
- **Hover**: Enhanced shadow with yellow glow

### Mission Card
- **Always**: Orange gradient background
- **Hover**: Enhanced shadow with orange glow

### Desktop (> 1024px)
- Crypto grid: 5 columns
- Feature grid: 2 columns (2x2)
- Max width: 1280px
- Optimal spacing

## 🎯 User Journey

1. **Land on page** → See hero title
2. **Scroll down** → See search input
3. **Enter address** → Click Check
4. **View ad** (if implemented) → Close ad
5. **While scrolling** → See premium info section
6. **Read about service** → Understand features
7. **See crypto options** → Know what's supported
8. **Read warnings** → Understand safety
9. **Continue scrolling** → See Bitcoin price
10. **Ready to search** → Return to top or search again
