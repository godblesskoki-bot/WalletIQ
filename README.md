# WalletIQ Logo

## 📁 Place Your Logo Here

Add your prepared logo file to this directory:

```
public/images/walletiq-logo.png
```

## ✅ Requirements

- **File name**: `walletiq-logo.png` (exact name)
- **Format**: PNG with transparency
- **Size**: 512x512px or larger (square)
- **Background**: Transparent
- **Content**: Logo symbol only (no text)
- **Optimized**: < 100KB recommended

## 📖 Instructions

See `LOGO_INTEGRATION_INSTRUCTIONS.md` in the project root for detailed steps on how to:
1. Download your logo
2. Remove background and text
3. Resize and optimize
4. Place it in this directory
